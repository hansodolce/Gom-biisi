# Gom-biisi

Traitement de texte léger dans le navigateur, avec une interface en mooré.

- `index.html` : l'application complète, en un seul fichier.
- `vercel.json` : réglages d'hébergement pour Vercel (site statique, sans étape de compilation).

Déploiement : importer ce dossier dans Vercel (Framework : « Other », sans commande de build), puis ajouter le domaine gom-biisi.app dans Settings > Domains.
